# 天线设计信息理解 MCP 模块说明

## 目标与边界

本模块接收受控根目录中的本地 PDF 或图像，输出带证据的 `AntennaDesignSpec`。它不连接 HFSS，不执行 PyAEDT，不运行求解，也不把不完整规格直接转换为 HFSS 操作。

## 核心接口

`PathPolicy` 负责输入根目录、后缀、大小和输出 ID 约束；`ArtifactStore` 负责 JSON 产物；`ProviderRegistry` 负责 provider 能力状态；`HTTPPerceptionProvider` 通过版本化 HTTP/JSON 调用外部 OCR/VLM sidecar；`IntelligenceService` 负责摘要、证据和规格编排；`tools/extraction.py` 暴露五个 MCP tools。

## 数据流

```mermaid
flowchart LR
    A[本地文件] --> B[inspect_input]
    B --> C[输入摘要产物]
    C --> D[Provider Registry]
    D --> E[证据产物]
    E --> F[AntennaDesignSpec]
    F --> G[本地 Agent]
    G --> H[现有 HFSS MCP]
```

## 验证方式

离线测试覆盖路径安全、schema、provider、HTTP sidecar 协议、产物、服务编排、MCP tool/resource 注册和中文部署文档。模型 runtime 不进入 MCP 进程。

## 已知限制

没有配置 sidecar 时不能自动读取截图文字或图形；场景三中的去耦结构精确轮廓、端口积分线、辐射区域和完整尺寸表必须补充后才能进行严格论文复现。
