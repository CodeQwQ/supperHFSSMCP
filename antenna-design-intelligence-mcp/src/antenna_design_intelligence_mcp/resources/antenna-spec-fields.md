# AntennaDesignSpec 字段说明

每条结论必须关联 `evidence_ids`。证据包含输入摘要、页码或图像区域、原文/人工观察、provider 和置信度。

| 字段 | 含义 | 建模前要求 |
|---|---|---|
| `antenna_family` | 天线类别 | 至少确认拓扑类别 |
| `targets` | 频段与性能目标 | 目标频率和单位必须确认 |
| `materials` | 基板、导体和介质 | 介电常数、损耗角正切和厚度分别记录 |
| `dimensions` | 有语义角色的尺寸 | 数值、单位、状态和证据必须齐全 |
| `geometry_relations` | 图中的相对位置与层关系 | 不能把模糊视觉观察当作精确尺寸 |
| `unresolved_fields` | 缺失且需补充的字段 | 端口、积分线、airbox 和边界缺失时必须列出 |
| `contradictions` | 不同证据之间的矛盾 | agent 必须停止静默合并 |

场景三的典型已确认字段包括 5.725–5.825 GHz、`εr=4.6`、`tanδ=0.001` 和两天线中心距 12.9 mm；去耦结构精确轮廓、端口积分线和辐射区域仍可能需要补充。
