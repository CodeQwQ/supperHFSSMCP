# 双 HTTP MCP Windows 离线包 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有离线包扩展为同时启动 HFSS MCP 和天线设计信息 MCP 的 Windows Server 2016 可用 HTTP 包。

**Architecture:** 保留两个独立 Python MCP 进程，由 PowerShell 启动器设置各自环境变量、记录 PID 并统一停止。复用现有可移植 CPython 和 `.venv` site-packages，不引入模型或 Windows 服务注册。

**Tech Stack:** PowerShell 5.1、CPython 3.12、MCP FastMCP、现有两个 Python 包、ZIP。
