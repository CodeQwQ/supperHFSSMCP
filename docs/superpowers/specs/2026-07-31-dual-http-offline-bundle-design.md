# 双 HTTP MCP Windows 离线包设计

## 目标

构建一个自带 CPython 运行时和依赖的 Windows 离线包，通过一个启动脚本同时启动现有 HFSS MCP 与独立天线设计信息 MCP；两个服务保持独立进程并使用 `streamable-http`。

## 方案

沿用现有离线包构建流程，新增第二个应用源码目录、天线 MCP 配置、双进程启动器和停止/健康检查脚本。默认端口为 HFSS MCP `8000`、天线设计信息 MCP `8010`，可由配置覆盖。启动器只负责进程编排，不合并两个 MCP 的代码或运行时状态。

## 边界

本次不打包 OCR/VLM 模型，不注册 Windows 服务，不改变两个 MCP 的业务工具和资源接口。HFSS 仍要求目标机安装 Ansys Electronics Desktop/HFSS，离线包只提供 Python 和项目依赖。

## 验证

构建后验证：内置 Python 导入两个包；解压副本可启动两个 HTTP 进程；两个端口可建立 TCP 连接；健康检查能识别两个进程；停止脚本能结束启动器及子进程；压缩包不包含模型、缓存和用户数据。
