# 仿真状态真实 HFSS 验证

## 版本信息

- 日期：2026-07-27
- 环境：Ansys Electronics Desktop Student 2025 R2
- 后端：PyAEDT 1.2.0
- MCP transport：streamable HTTP
- 状态：通过

## 验证目的

本次验证覆盖仿真状态修复：

- `run_simulation` 不再接受或实现 `wait_for_completion=false` 的假异步逻辑。
- 求解前必须执行有证据的 `validate_design`。
- 真实 PyAEDT 后端提交求解后，通过 AEDT 仿真状态 API 定时轮询，不靠固定超时判断。
- 验收必须包含 HFSS 窗口截图，证明 validation 和 simulation 对应的是可见的真实 HFSS 会话。

## 验证流程

通过临时 MCP HTTP 服务连接 Student AEDT gRPC 会话，创建 `HFSS_RealSolve_State_20260727` 设计，使用 dipole 模板创建最小天线结构，并创建轻量 setup/sweep：

1. `connect_hfss(machine=localhost, port=50163, student_version=true, non_graphical=false)`
2. `create_hfss_design`
3. `create_dipole_antenna`
4. `create_simulation_setup(setup_name=SetupRealSolve20260727, sweep_points=3, max_passes=1, min_passes=1)`
5. `validate_design`
6. `run_simulation(setup_name=SetupRealSolve20260727)`
7. `release_connection(save_project=false)`
