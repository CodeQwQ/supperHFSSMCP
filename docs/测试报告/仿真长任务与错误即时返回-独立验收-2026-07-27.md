# 仿真长任务与错误即时返回独立验收

## 环境

- 独立验收 MCP client：`mcp.ClientSession + streamable_http_client`
- MCP endpoint：`http://127.0.0.1:8064/mcp`
- HFSS：Ansys Electronics Desktop Student 2025 R2
- 证据目录：[独立验收-20260727](./证据/独立验收-20260727)

## 正向流程

独立 client 依次执行 `validate_design`、`run_simulation` 和 `get_simulation_job`。真实 HFSS validation 返回 `valid=true`、`api=validate_full_design` 和 `Design validation check PASSED.`。

`run_simulation` 在约 0.029 秒内返回真实 job `job-0001`，状态为 `running`；第一个 MCP client 随后断开，第二个独立 client 成功查询同一个 job。AEDT 状态 API 共检查 11 次，前 10 次为 `running=true`，第 11 次为 `running=false`，最终 job 为 `completed`。HFSS 窗口截图中可见 `Starting simulation engine ... RUNNING`，完成截图窗口标题包含 `SOLVED`。

## 失败流程

独立 client 创建空 HFSS design，只创建 setup/sweep 后调用 `run_simulation`。约 0.028 秒内返回 `job-0002` failed，错误包含真实 HFSS validation 消息：没有对象、没有 solve-inside 材料、Driven 问题没有 excitation。该流程没有调用 S 参数提取。

## 资源释放

求解完成后 `release_connection` 成功，AEDT PID 退出，gRPC 端口释放。正向、失败、重连和资源释放的完整工具响应见 [independent-acceptance.json](./证据/独立验收-20260727/independent-acceptance.json)。求解运行截图为 [04-during-or-after-solver.bmp](./证据/独立验收-20260727/04-during-or-after-solver.bmp)，验证失败截图为 [06-failure-validation.bmp](./证据/独立验收-20260727/06-failure-validation.bmp)。
