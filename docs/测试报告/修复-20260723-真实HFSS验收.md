## 验收范围

本次验收覆盖用户反馈的五类问题：

1. HFSS 图形界面模式是否可见。
2. `release_connection` 默认是否保存、释放 MCP 资源并关闭 AEDT 进程。
3. `release_connection(close_desktop=false)` 是否释放 MCP 控制权但保留 AEDT GUI。
4. 仿真失败时是否返回真实 HFSS validation / error 信息。
5. 偶极子 workflow 是否为两片金属臂设置 Perfect E。

## 遗留观察

1. Student 版 AEDT 连续多实例测试时，若前一个 GUI 窗口被刻意保留，后续新连接可能出现连接等待变长。验收脚本已将真实连接等待放宽到 180 秒；真实多用户服务器仍需要后续做队列、独占锁或会话 broker。
2. Windows 普通屏幕截图会被前台窗口遮挡。真实 GUI 验收应使用窗口句柄和 `PrintWindow` 类方式直接截取 AEDT 窗口，而不是依赖当前桌面焦点。
