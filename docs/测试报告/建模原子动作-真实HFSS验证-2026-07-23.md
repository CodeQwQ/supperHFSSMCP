# 建模原子动作真实 HFSS 验证

## 版本信息

- 日期：2026-07-23
- 环境：Ansys Electronics Desktop Student 2025 R2
- 后端：PyAEDT 1.2.0
- MCP transport：streamable HTTP
- 状态：通过

## 验证范围

本次验证覆盖新增建模原子动作：

- `create_model_sheet`
- `create_model_box`
- `assign_perfect_e`
- `assign_radiation_boundary`
- `create_lumped_port`
- `create_simulation_setup`
- `validate_design`
- `release_connection`

## 验证流程

通过临时 MCP HTTP 服务连接 Student AEDT gRPC 会话，创建 `HFSS_ModelingAtoms_OK_*` 设计，然后只使用原子动作拼出一个中心馈电偶极子最小结构：

1. 创建两个 copper sheet 作为偶极子两臂。
2. 创建一个 XY air sheet 作为 lumped port sheet。
3. 创建 airbox。
4. 给两臂分配 Perfect E。
5. 给 airbox 分配 Radiation。
6. 在 port sheet 上创建 lumped port。
7. 创建 setup 和 sweep。
8. 执行 `validate_design`。
9. 调用 `release_connection(save_project=false)` 释放资源。

## 观察

首次 smoke test 使用了错误的 XZ port sheet 和不在该 sheet 平面内的积分线，真实 HFSS 返回原始错误：`both endpoints of port lines must lie on the port`。这不是工具注册或后端转发失败，而是端口几何约束错误；该约束已补充到 `docs/modeling.md`。
