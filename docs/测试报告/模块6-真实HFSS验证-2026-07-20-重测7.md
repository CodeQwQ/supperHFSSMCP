## 根因证据

服务端日志显示，`create_patch_antenna` 在真实 AEDT worker 中抛出：

```text
object of type 'int' has no len()
```

此后同一 worker 的 gRPC 调用连续失败：

```text
Failed to execute gRPC AEDT command: GetTopDesignList
Failed to execute gRPC AEDT command: GetMessages
type object 'HfssConstants' has no attribute 'default_solution'
Failed to execute gRPC AEDT command: GetRegistryString
```

这说明本轮的首要阻塞点已从 `Hfss.analyze()` 保存失败推进到贴片天线真实几何创建阶段。由于建模调用未成功返回，后续验证不能证明求解链路或结果分析链路可用。
