# 模块 7 真实 HFSS 验收报告

## 1. 验收结论

**FAIL**

本次验收使用真实 Ansys Electronics Desktop Student 2025 R2、真实 streamable-http MCP 服务和真实 MCP `ClientSession`。MCP 初始化、工具发现、脚本发现、真实 HFSS gRPC 连接以及 native AEDT CLI 执行成功；但 `pyaedt` runner 和 COM adapter 均未完成真实执行，因此模块 7 不通过。

## 3. MCP 请求链路

客户端依次完成：

1. `initialize`
2. `tools/list`
3. `list_automation_scripts`
4. `connect_hfss`
5. `run_automation_script`，分别使用 `pyaedt`、`native`、`com`

`tools/list` 返回 28 个工具，其中包含 `list_automation_scripts` 和 `run_automation_script`。脚本发现结果为服务器登记的 `aedt_probe`：

```text
E:\LLMproject\HFSSagent\scripts\aedt_probe.py
```

真实 `connect_hfss` 调用参数包含：

```json
{
  "student_version": true,
  "desktop_version": "2025.2",
  "machine": "localhost",
  "port": 53387,
  "non_graphical": false,
  "new_desktop": false,
  "connect_timeout_seconds": 45
}
```

连接返回 `status="ok"`，并读取到真实工程、Design 和 6 个模型对象。

```text

```

实际命令：

```text

```

实际返回：


该结果证明真实 `ansysedtsv.exe -RunScriptAndExit` 能够执行登记脚本并生成 artifact/log。但本次脚本未从 native 运行上下文取得当前工程和 Design 名称，因此只能判定 native 执行链路成功，不能将其扩展为完整的项目状态探测成功。

日志：

```text

```

### 4.3 COM adapter：FAIL

真实 MCP 调用返回 `status="error"`，错误为：

```text
Unable to attach to active AEDT COM application: (-2147221005, '无效的类字符串', None, None)
```

因此 `win32com.client.GetActiveObject("Ansoft.ElectronicsDesktop")` 未能取得真实 AEDT COM 对象，脚本没有进入 `RunScript` 阶段，也没有生成 artifact 或 COM log。
